[english](#english) • [русский](#русский)

## english

lightweight version of tdesktop with additional features and quality-of-life improvements

### features

- full ghost mode (offline reading, hidden typing status)
- message screenshot (one-click copy of selected messages to clipboard)
- lazy loading & optimized startup performance
- removed ads
- bloat-free (removed useless features like wallet and video messages)
- clean ui without clutter

## русский

облегченная версия tdesktop с дополнительными полезными функциями

### возможности

- полноценный режим призрака (нечиталка сообщений, скрытый статус набора)
- быстрый скриншот сообщений (копирование выделенных сообщений в буфер обмена в один клик)
- lazy-загрузка и ускоренный запуск
- вырезана реклама
- вырезаны бесполезные функции (кошелек, видеосообщения и лишний мусор)
- чистый интерфейс без спама
